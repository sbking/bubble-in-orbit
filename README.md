# Bubble in Orbit

Interactive 64-bar WebAudio DAW and companion musical atlas in the browser.

- **Interactive Web DAW:** https://sbking.github.io/bubble-in-orbit/
- **Interactive 64-Bar Atlas:** https://sbking.github.io/bubble-in-orbit/atlas.html

## Sound & Instrument Credits

- **1977 Rhodes Mark I Stage 73 samples (`08b_warm_rhodes_tremolo`, `06d_fugue_rhodes`):** Based on [jRhodes3d](https://github.com/sfzinstruments/jlearman.jRhodes3d) by Jeff Learman (CC0 for musical works / CC BY 4.0 for sample redistribution).

  - [Dragonfly Hall Reverb](https://michaelwillis.github.io/dragonfly-reverb/)
